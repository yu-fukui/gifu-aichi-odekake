# ぎふあいちおでかけ 運用ボード

投稿文をつくる AI が毎晩これを読みます（最優先のルール）。開発・運用部が、一時的な指示をここに書きます。
期限のある指示には、いつまでかを書き、過ぎたら消してください。

## いまの指示

- **始まってから1か月をこえた催し・上映・展示は出さない（2026-11-04〜、共通の作りに入るまで。代表「4ヶ月前のイベントは出さない」）**
  11/3 23時に、7月3日から上映中のプラネタリウムを紹介してしまいました。
  1. ネタ帳の行で、始まった日が投稿の日より1か月以上前の催し・上映・展示・フェア・スタンプラリー・期間限定メニューは、選ばない（会期中でも出さない）
  2. 終わりが近い知らせ（「今週末まで」「あと3日」など、終わる日が投稿の日から7日以内）だけは別。そのときは終わる日を1行目に書く
  3. 終了日未定・通年のものも、始まった日から1か月をこえたら出さない
  4. お店・施設そのものの紹介（新店・施設の案内）は、この決まりの外

- **閲覧の落ち込みへの手当て（2026-10-26〜11/9。代表「ここ数日の数字悪いですね」）**
  10/23 から閲覧が前の週の1/5ほどに落ちています。10/16〜25 の投稿では、新店（オープン・リニューアル）の閲覧の中央値が約2,900、催しは約550、
  名古屋の話題は名古屋以外の約3倍でした。1日の中身を次のように寄せてください。
  1. ネタ帳に新店（オープン・リニューアル・期間限定ショップ）があれば、1日に3本以上は新店にする。名古屋・栄・名駅・大きなモールなど、人が集まる場所の新店を先に
  2. 小さな町の行事・講座・参加者募集は、1日2本までにする
  3. 名古屋の話題（催し・新店）を1日に3本以上入れる。岐阜・三河の話題も、名の知れた場所（岐阜公園・長良川・犬山城・ラグーナなど）を先に
  4. 事実は出典にあるものだけ、という決まりは今までどおり

- **14:00 の問いかけは「暮らし・家の話」だけにする（2026-11-03〜11/17 の2週間。代表の判断、運用部・ぎふあいち）**
  ぎふあいちでは、名所・施設・紅葉・イルミを選ばせる問いの返信が一桁〜二桁でした（10/26 泊まる町 5、10/27 イルミネーション 16）。
  福井・石川で返信が多かったのは暮らし・家の話の問いです（「『冬が来たな』と感じる瞬間」返信9、「電車で出かけるなら、どの線」返信11、「家の器」「家の味」）。
  1. 題材は、季節の合図・家の食べもの・家の道具や器・ふだんの移動（電車・車）・地元の言葉や習慣 にする
  2. 観光地・施設・名所・紅葉の名所・イルミネーションの会場・泊まる町を、選択肢に並べない。選ばせない
  3. 作成の指示の「4つのくくり」のうち ①出かける先・③泊まる・温泉 は、この2週間は使わない。②食べもの・飲みもの（家で作る・食べるもの）と ④季節（合図・家での支度）から、暮らしの側で聞く
  4. 例：「寒くなってきたな、と感じる合図は？」「家で冬にかならず出す器や道具は？」「岐阜・愛知の家の味噌、何味噌ですか？」「名古屋への行き来は、電車と車どっち？」
